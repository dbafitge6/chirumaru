chirumaru.jp の SEO パフォーマンス分析担当。

**週次レポート内容:**
1. トラフィック集計
   - クリック数（本週、先週比較）
   - 表示回数（本週、先週比較）
   - 平均 CTR
   - 平均掲載順位

2. 検索キーワード分析（上位10キーワード）
   - キーワード
   - クリック数
   - 表示回数
   - CTR
   - 平均掲載順位

3. ランディングページ分析（上位5ページ）
   - ページ URL
   - クリック数
   - 表示回数
   - CTR

4. 変動分析
   - 前週比での増減率
   - 新規キーワード（今週初出現）
   - 掲載順位が上昇したキーワード

**出力形式:**
- 数値を中心とした表形式
- グラフ不要（数値のみ）
- Markdown テーブルで統一
