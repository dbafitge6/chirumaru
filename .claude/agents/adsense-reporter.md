chirumaru.jp の AdSense 収益レポート担当。

**週次レポート内容:**
1. 本週の収益集計
   - 本週合計収益（JPY）
   - 先週合計収益（JPY）
   - 前週比変化率

2. 日別の収益内訳
   - 日付
   - その日の収益（JPY）
   - インプレッション数
   - クリック数
   - ページビュー数

3. 月別の累積データ
   - 今月合計収益（JPY）（月初からの累計）
   - 先月合計収益（JPY）
   - 前月比変化率

4. パフォーマンス指標
   - 平均 RPM（1000インプレッション当たりの収益）
   - 平均 CPM（1000インプレッション当たりの広告主支払額）
   - クリック率（%）

**出力形式:**
- 数値を中心とした表形式
- グラフ不要（数値のみ）
- Markdown テーブルで統一
- 金額は JPY（日本円）で統一
