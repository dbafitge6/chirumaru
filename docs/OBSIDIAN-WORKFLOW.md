# Obsidian × chirumaru 自動登録ワークフロー

Obsidian の「chirumaru-追加店舗リスト.md」に店舗名を追加すると、Claude Code が自動的に調査して Airtable に登録します。

## セットアップ完了 ✅

### ファイル配置
- **Obsidian テンプレート**: `~/Documents/Obsidian Vault/chirumaru-追加店舗リスト.md`
- **処理スクリプト**: `scripts/obsidian-to-airtable.py`

## 使い方

### 1️⃣ Obsidian に店舗名を追加

`~/Documents/Obsidian Vault/chirumaru-追加店舗リスト.md` を開いて、「未処理」セクションに店舗名を追加：

```markdown
## 未処理（新規追加待ち）

```
- コーヒーシテン
- パン屋さん
- スイーツカフェ ☆
```
```

複数個追加可能です。

### 2️⃣ Claude Code に依頼

Claude Code に以下のように言ってください：

```
Obsidian の chirumaru-追加店舗リスト.md から新規店舗を取得して、
調査して Airtable に登録してくれ
```

### 3️⃣ 自動処理実行

以下が自動実行されます：

```
📖 Obsidian から店舗リストを読み込み
  ↓
🔍 各店舗を WebSearch で調査
  ↓
📝 住所・電話・営業時間・タグを取得
  ↓
✍️ Airtable に新規レコード登録
  ↓
📊 Obsidian の「完了」セクションに移動
```

### 4️⃣ 結果確認

- **Obsidian**: 「完了」セクションで登録済み店舗を確認
- **Airtable**: 実際に登録されたレコードを確認

## 処理の流れ

### 自動検出される情報
- ✅ 店舗名
- ✅ 住所（番地付き）
- ✅ 電話番号
- ✅ 営業時間（定休日含む）
- ✅ Website（公式サイト / Instagram）
- ✅ タグ（業態・特徴）
- ✅ メモ（概要）

### データ品質基準
すべての登録情報は「ペントイト/Nolla Mura形式」に準拠：
- 住所：番地を含む（例：新潟市西区赤塚1566）
- 電話：記載されている
- 営業時間：定休日を含む統合形式（例：10:00-17:00 月・火定休）
- タグ：業態+特徴（例：カフェ/スイーツ）
- Website：https://から始まる形式

## よくある質問

**Q: 複数の店舗を一度に追加できる？**
A: はい。「未処理」セクションに複数の店舗名を追加して、一度に処理できます。

**Q: 情報が不足している場合は？**
A: WebSearch で調査して、可能な限り補完します。それでも不足の場合は、メモに「情報未確認」と記載されます。

**Q: Airtable に登録された後は？**
A: Obsidian の「完了」セクションに自動移動。Airtable のレコード ID も記録されます。

**Q: 削除・修正したい場合は？**
A: 「未処理」セクションから削除、または「完了」セクションを編集してください。

→ 予算回復を待つか、手動で情報を補完してください
